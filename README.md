# RSSM and PlaNet: an illustrated explanation

A beginner-friendly guide to recurrent state-space models and PlaNet, including an interactive observation/imagination diagram, model-component explanations, and a walkthrough of learning and planning.

**Website:** https://Vineet5-Data.github.io/rssm-planet-guide/

Open `index.html` locally or view the GitHub Pages website. No build step or dependencies are required.

## Sources

- [Learning Latent Dynamics for Planning from Pixels (PlaNet)](https://arxiv.org/abs/1811.04551)
- [DreamerV3](https://arxiv.org/abs/2301.04104)

The reference diagram was supplied with the guide request. Its Dreamer-specific components are distinguished from the original PlaNet architecture in the guide.

GitHub Pages serves the root directory of the `main` branch.
